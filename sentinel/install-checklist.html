🪟Phase 0 · Fresh Windows sanity

✓
Run Windows Update until it stops finding things
Settings → Windows Update. Boring, but installer weirdness loves a half-updated machine.
✓
Upgrading? Remove any old SENTINEL copy first
No old version on this machine — check this box and move on. Otherwise: restart the PC (stops everything — SENTINEL has no services or installers, it's just a folder), delete the old folder (often C:\sentinel-pro — this also removes the old .env, which is intentional), then drop the retired broker library:
pip uninstall ib_insync -y
Keep TWS, Ollama + its model, Python, and git — the new install reuses them all.
✓
Confirm winget works
Open PowerShell and check — it ships with Windows 11. If missing, install "App Installer" from the Microsoft Store.
winget --version
If any installer ever dies with error 1603: your Windows Installer service is being weird (ask me how I know). Workaround that saved this project: extract the MSI with lessmsi instead of installing it.

🧰Phase 1 · Core tooling

✓
Install Git
winget install Git.Git
✓
Install Python 3.10+ — CHECK "Add python.exe to PATH"
From python.org. The PATH checkbox on the first installer screen is the single most-missed step in this whole list. Verify after:
python --version
✓
Install the .NET 8 SDK
winget install Microsoft.DotNet.SDK.8
Verify (new terminal): dotnet --list-sdks shows an 8.x line.

🏦Phase 2 · Broker layer (IBKR)

✓
Install TWS or IB Gateway
From interactivebrokers.com. Gateway is lighter and perfect for SENTINEL (no charting UI). Remember: one login per username at a time — Gateway and TWS fight over the same session.
✓
Log in with the entitled account
Funded login = real-time data. Subscriptions live on the account, not the machine: CME real-time + depth (Level 2), CBOE SPX/SPXW options.
✓
Enable the API — READ-ONLY
Global Configuration → API → Settings: ✅ Enable ActiveX and Socket Clients · ✅ Read-Only API (the broker-side no-execution lock) · ✅ localhost only.
Port cheat-sheet: TWS live 7496 · TWS paper 7497 · Gateway live 4001 · Gateway paper 4002. Gateway users add TWS_PORT=400x to both .env files later.

Riley: you need a (free) GitHub account and Jordan must have added it as a collaborator first — ask him if the clone says "repository not found". Run this from the folder you want it in (e.g. C:\sentinel-pro\); a browser sign-in pops up — sign in as yourself.

🐍Phase 5 · Deploy the Python cockpit (production)

✓
Install dependencies
cd sentinel-pro pip install -r requirements.txt
✓
Configure .env
copy .env.example .env
Set SENTINEL_MODE=live (or paper), Gateway port override if applicable, and the fresh Discord webhook — never the old compromised one.
✓
Run preflight — fix every [FAIL] before launching
python preflight.py
✓
Launch everything
powershell -ExecutionPolicy Bypass -File .\start-sentinel.ps1
Verify: bridge window logs #N ES=… every ~2 s · dashboard badge ≠ "Bridge Offline" · feed heartbeat goes green within minutes.
✓
Open the cockpit and see live numbers
localhost:8080/sentinel_pro_dashboard.html — price ticking, DOM ladder full (10 levels = depth subscription confirmed), CVD moving, IV showing "data ok".
