Control options

Four ways to draw the same three things: the pinned row, the section and status filters, and the phone nav. No pill shapes in any of them. Each option shows the same real data, with Section = Games and Status = live chosen, so the rows under it are the 11 real live games (first 5). Resize the window to see how each one reflows.

A · Two filter buttons, as in the donor

My pick

The donor's own data-table toolbar. The 16 filter pills become 2 square-cornered buttons with dashed edges. Each opens a checklist with counts, and a chosen value shows inside the button. Pinned items are plain buttons with no outline. On a phone the nav folds into one Menu button. Fewest controls on screen.
