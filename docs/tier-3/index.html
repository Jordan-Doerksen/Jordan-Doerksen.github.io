10 attract screens, at most 6 running at once. Each is a real canvas loop, so that is a CPU budget rather than a layout preference: a panel starts when it comes near the viewport and stops when it goes well past.
Playing a game stops every panel — one loop at a time.
With JavaScript off no panel mounts and the list below is the page, every game still one click away. Under reduced motion nothing is mounted at all.
