The trading desk. Does it hold up?

A read-only market desk. It never places an order. The interesting question is not what it does — it is whether it can be trusted when it says something. This page is the evidence, including the parts that fail.

Step 1What can go wrong

A desk that reports the wrong number quietly is worse than one that crashes. These are the failure classes the harness actually mutates, and how many guards stand against each.

Step 2What catches it

Every guard was driven into the failure it exists to catch, then the file was restored and the restore checked by SHA256. A test that has never failed proves nothing. The suite last ran green at 616 passed, 2 skipped.
